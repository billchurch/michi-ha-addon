# michi Home Assistant add-on

A Home Assistant add-on repository with one add-on, **Michi susu**: a
read-only network diagnostics node for michi, running the signed image
`ghcr.io/billchurch/michi-susud`. See [michi-susud/DOCS.md](michi-susud/DOCS.md).

Add this repository in Home Assistant under Settings → Add-ons → Add-on
Store → ⋮ → Repositories: `https://github.com/billchurch/michi-ha-addon`.

This is a mirror of the add-on in michi's private source repository.
